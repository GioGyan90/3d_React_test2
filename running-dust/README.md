# Running Dust · Three.js 跑步扬尘特效

在线预览（GitHub Pages）：https://giogyan90.github.io/3d_React_test2/running-dust/

源码：https://github.com/GioGyan90/3d_React_test2/tree/main/running-dust/

## 目标与现状

这是独立于 elemental-pocket（四元素进球）、power-charge（力量槽）、rainbow-cue（母球彩虹拖尾）的第七个动态特效展览页面，面向 Lucky Break 和其他 Three.js 游戏复用。

跑步中的低模数腿脚交替抬起、落地。每次触地从鞋跟附近喷出几团大小各异的卡通烟云，它们向角色后方（世界 X 负方向）漂移、略微上浮、横向扩散、体积放大，最后透明消失。不是平面序列帧或贴片，每一簇由 4 个低多面体几何球组成。

## 文件与技术

- index.html：独立的展览、实时画布、互动按钮和速度/烟团数量控制。
- style.css：沿用深蓝清爽日式游戏特效实验室风格，适配桌面/手机。
- scene.js：Three.js 0.160.1（固定版本 CDN）；低面角色下半身、程序化脚步、落地事件、DustEmitter 尘土池、卡通云动画、视角控制。
- HANDOFF.md：跨聊天窗口继续调试的任务说明。

没有新增构建工具、图片资产或后端；GitHub Pages 静态路径即可运行。首次打开需能访问 cdn.jsdelivr.net 提供的 Three.js ES 模块，并使用支持 WebGL 的浏览器。

## 当前交互

- 页面打开后默认跑步，左右脚交替落地自动扬尘。
- 「暂停跑步 / 继续跑步」；「单次踩踏」可独立生成一簇烟尘；「清空烟尘并复位」。
- 跑步速度：0.50×–2.00×（默认 1.00×）；每次踩踏烟团数量：2–9 团（默认 5 团）。
- 「暖沙色」和「冷灰色」配色；拖动场景旋转观察，滚轮缩放。
- HUD 显示累计发射、当前存活烟团和步伐周期数。
- 对 prefers-reduced-motion 降低最大每脚烟团数及对象池数量。

## 核心设计

DustEmitter 是可独立复用的 Three.js 对象池控制器：

- new DustEmitter(scene) 生成并复用有限数量的烟团 Mesh，避免每步都构造新几何和材质。
- burst(x, z, n, strength) 从落脚位置生成 n 个烟团。速度方向默认为负 X，接入游戏时必须根据实际移动方向旋转。
- update(dt) 按秒数更新世界空间位置、轻微竖直加速度、膨胀和透明度。
- setTone('sand' | 'slate') 切换颜色。
- clear() 停止已有烟团；dispose() 清理对象、材质。

低模腿和鞋仅用于展示“脚碰地时发射尘土”的正确时机，不是正式可复用人物骨骼。接入人物动画系统时建议取左右脚足底的 world position 和落地事件来触发特效；不要依据 FPS 或时间间隔凭空产生烟团。游戏自己负责统一场景、渲染器、时间步长、相机与脚底真实位置。

## 验收和后续

1. 打开页面后确认每次着地均有错落烟团向后抛出，鞋子抬起时不会持续冒烟。
2. 暂停状态持续更新并淡出已有烟团，但不再生成新烟团；单次踩踏仍可播放特效。
3. 切换 2–9 团数量、0.5–2.0 倍跑速和冷暖色，检查烟尘大小、后移速度、生命周期。
4. 从多个角度检查脚底是否穿地、腿关节对齐、团簇是否过大或过薄、移动端查看性能。
5. 用户满意后可将 DustEmitter 拆为独立 TS/JS 模块，与游戏角色及真实地面材质联动。

目前只做了程序/逻辑检查，最终浏览器可视效果仍需手动验收；如有问题在后续聊天中继续调整。
